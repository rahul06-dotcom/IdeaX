The Problem

- Students with hearing impairments may miss important classroom explanations and instructions.
- Verbal announcements can be difficult to follow in noisy classrooms.
- Important information may not be accessible to every student at the same time.
- Traditional classroom communication may not meet the needs of students with different abilities.

Our Solution

**ClassClear is an accessible classroom communication website that makes spoken information easier to access.**

**Live Speech-to-Text:** Converts a teacher's speech into text captions in real time.
**Instant Announcements:** Allows teachers to publish notices and important classroom updates.
**Separate Dashboards:** Provides dedicated teacher and student views.
**Live Student Display:** Shares captions and announcements with connected students' screens.
**Inclusive Learning:** Helps students access classroom information through text.

Key Features

- Real-time speech recognition and captions.
- Instant classroom announcements.
- Teacher and student dashboards.
- Live communication using Socket.IO.
- Simple, beginner-friendly website interface.
- Designed to support more inclusive classrooms.

How It Works

1. The teacher opens the ClassClear teacher dashboard.
2. The teacher starts speech recognition or posts an announcement.
3. Recognized speech is converted into text and sent through the server.
4. Connected students see the live captions and announcements on their screens.
5. Students can follow important classroom information more easily.

Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Real-Time Communication:** Socket.IO
- **Speech Recognition:** Web Speech API

Run It Locally

bash
git clone <your-github-repository-url>
cd ClassClear
npm install
node server.js


Open `http://localhost:3000` in your browser.

For multiple devices, connect them to the same network and use the host computer's local IP address. Allow microphone access and use a supported browser for speech recognition.

Impact

ClassClear aims to reduce communication barriers in classrooms by making teachers' spoken instructions and announcements available as text. It supports accessible learning and helps create a more inclusive educational environment.
